# Logan's Math — Web App Package

This folder is ready to publish as a static website.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `logans-math`).
2. Upload every file in this folder to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish and open the URL shown on that Pages screen.

## Install on a Chromebook
After the site is published over HTTPS, open it in Chrome. Use the install icon in the address bar if offered, or Chrome menu → **Install page as app** / **Create shortcut** (wording varies).

The app shell can be cached for quicker repeat opening. Online game catalogs and other external services still require their source servers and network access; the service worker does not bypass network restrictions.
